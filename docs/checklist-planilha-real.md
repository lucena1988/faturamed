# Checklist para Pedir a Planilha Real

Enviar para a empresa uma solicitacao simples e objetiva.

## Arquivos desejados

Pedir exemplos, preferencialmente anonimizados, de:

- planilha de faturamento
- relatorio de producao
- relatorio de consultas
- relatorio de exames/procedimentos
- planilhas auxiliares usadas na conferencia manual

## Informacoes importantes

Perguntar:

1. Qual arquivo representa o que foi produzido?
2. Qual arquivo representa o que foi faturado?
3. Existe algum numero de atendimento, guia, senha ou autorizacao?
4. Existe codigo do procedimento ou apenas descricao?
5. O medico vem sempre preenchido?
6. O paciente vem com CPF, carteirinha, prontuario ou outro identificador?
7. O valor informado e unitario, total ou ambos?
8. Como a empresa identifica hoje uma divergencia?
9. Quais erros acontecem com mais frequencia?
10. Qual relatorio final eles esperam receber?

## Cuidados com dados sensiveis

Solicitar que dados pessoais sejam anonimizados quando possivel.

Campos que podem conter dados sensiveis:

- nome do paciente
- CPF
- numero da carteirinha
- numero do prontuario
- data de nascimento
- telefone
- endereco

## Modelo de mensagem para a empresa

```text
Ola!

Para desenharmos corretamente o sistema de conferencia de faturamento, precisamos de exemplos das planilhas ou relatorios usados atualmente no processo.

Se possivel, envie:

- uma planilha de faturamento
- um relatorio ou planilha de producao
- qualquer planilha auxiliar usada na conferencia

Pode ser uma copia anonimizada, removendo ou substituindo dados pessoais de pacientes.

Tambem seria importante sabermos qual coluna voces usam hoje para cruzar as informacoes, como atendimento, guia, paciente, data, procedimento, medico, quantidade e valor.

Obrigado.
```
