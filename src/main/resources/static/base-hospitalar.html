1 Importar hospital

Como funciona

O arquivo original é guardado e cada procedimento distinto recebe um ID fixo, aguardando a produção médica.

Na atualização, procedimentos identificados com segurança mantêm o ID; ambiguidades e repetições seguem para análise. Depois, atualize a conciliação da produção.

Tipo automático classifica cada linha pela coluna Tipo, descrição ou código TUSS. Escolher um tipo aplica-o a todos os procedimentos do arquivo.

2 Importar produção médica

Como funciona

Clique na competência para ver os arquivos do hospital e das produções. Após importar outro arquivo hospitalar ou resolver duplicidades, use Atualizar conciliação na produção — isso cria nova versão preservando revisões e recebimentos.

Nenhuma importação.

Procedimentos hospitalares distintos pela versão atual de cada produção. Valores são subtotais confirmados.
